# Воспроизведение финального дообучения

Включены данные, начальные веса, исходные функции и точные рецепты финальной адаптации детектора и OCR. При распознавании обучение не запускается.

Команды выполняются из корня полного комплекта с установленным окружением CUDA:

```powershell
& "$env:LOCALAPPDATA\VolgaANPR\cuda\Scripts\python.exe" training/tools/reproduce.py --stage verify
& "$env:LOCALAPPDATA\VolgaANPR\cuda\Scripts\python.exe" training/tools/reproduce.py --stage detector --output "C:\volga-training-detector"
& "$env:LOCALAPPDATA\VolgaANPR\cuda\Scripts\python.exe" training/tools/reproduce.py --stage ocr --output "C:\volga-training-ocr"
```

Первая команда только проверяет файлы. Две следующие запускают обучение. Выходные каталоги должны быть новыми и находиться вне `training`. Нужны NVIDIA GPU, Python 3.12 и зависимости из автономного окружения CUDA.

Детектор: начальные веса F03, четыре эпохи, seed 20261019, 90 реальных train-объектов, 19 real val и 180 процедурных train-примеров. OCR: начальный checkpoint предыдущего этапа, seed 20261018, доля реальных данных 0,75, до 12 эпох, patience 3, лимит времени 1200 секунд. Подробные параметры находятся в `recipes`.

| Каталог | Содержимое |
|---|---|
| `initial` | Начальные веса двух моделей |
| `detector_data` | Изображения и аннотации детектора |
| `ocr_data` | Подготовленные тензоры и описания OCR-выборки |
| `recipes` | Параметры обучения |
| `source` | Исходные модули, используемые рецептом |
| `evidence` | Сведения о разбиении и исторических запусках |

Проверяется идентичность входных файлов и параметров. Побайтовое совпадение заново обученных весов на другой GPU не гарантируется; на OCR также влияет ограничение времени. Все ранние этапы обучения с нуля этот комплект не воспроизводит. Правовой статус фотографий и производных тензоров наследуется от исходных данных; отсутствующий документ Kaggle указан в `dataset/permissions`.
