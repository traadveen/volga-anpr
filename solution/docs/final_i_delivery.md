# Volga ANPR — FINAL-I

Распознавание российских автомобильных номеров на одном изображении или в папке. Детектор FINAL-I, OCR FINAL-H; веса, пороги, размер входа и правила распознавания зафиксированы. Профиль `russian_v1` применяется автоматически.

## Запуск

Нужен Windows x64 и Python 3.12 с установленными зависимостями из комплекта. Из папки `runtime`:

```powershell
D:/volga-runtime-cpu/Scripts/python.exe -I tools/final_i_runtime.py --input "D:/photos" --output "D:/results/result.csv" --device cpu
```

Для NVIDIA используйте среду CUDA и `--device cuda`. Можно указать отдельный файл вместо папки. Папка просматривается на одном уровне, без подпапок; поддерживаются JPG/JPEG/PNG/BMP. Порядок обработки — по именам файлов. В путях допустимы пробелы и кириллица.

Проверка целостности без загрузки нейросетей:

```powershell
python -I tools/final_i_runtime.py --verify-only
```

В рабочем проекте сохранён исследовательский запуск `tools/predict_images_i.py`. Переносимый запуск из этого комплекта проверяет собственные файлы и использует свои копии весов. Оригинальный конфиг сохранён в `provenance/final_i.original.json`; в рабочей копии изменены только пути к двум весам.

## Установка без интернета

Полный автономный комплект содержит соседние с `runtime` папку `wheels`, установщик и два lock-файла. Откройте его корневую папку и выберите **новую** папку окружения вне комплекта:

```powershell
python -I install_offline_runtime.py --variant cpu --environment D:/volga-runtime-cpu
# либо NVIDIA с драйвером, совместимым с CUDA 12.4:
python -I install_offline_runtime.py --variant cu124 --environment D:/volga-runtime-cuda
```

Python 3.12 и драйвер NVIDIA устанавливаются заранее. Установщик использует локальные wheels с проверкой SHA-256; доступ к сети не нужен. Существующее окружение он не заменяет. Полный комплект нельзя смешивать с файлами прежнего BEST-G.

Компактный ZIP содержит только `runtime`, код, веса и отчёт. Для него можно использовать уже установленную совместимую среду Python 3.12; зависимости перечислены в `requirements-inference.txt`. Wheels находятся только в полном автономном комплекте.

## Результат

`result.csv` — UTF-8, разделитель `;`, ровно четыре колонки:

```csv
image;plate_num;plate_type;confidence
```

На каждый найденный номер создаётся строка. Для изображения без распознанных номеров строк нет; их обработку подтверждает `result.trace.json`. Типы: `type1` — белый длинный, `type1a` — белый двухстрочный, `type1b` — жёлтый длинный. Неизвестные символы обозначаются `#`. Confidence — оценка модели, она не гарантирует верный текст.

Рядом сохраняются `result.trace.json` и `result.manifest.json`: результаты каждого изображения, SHA-256 входов и весов, версии библиотек, устройство и профиль. Пустой каталог, повреждённое изображение, отсутствующие или изменённые файлы возвращают ненулевой код завершения. При ошибке обработки прежний CSV не заменяется частичным результатом. Инференс блокирует Python TCP/DNS/UDP во время загрузки и работы моделей.

## Качество и границы проверки

По сохранённым измерениям: REAL VAL — 71/93 обнаруженных целевых номеров, 55/93 полностью верных ответов; отдельный проход по 40 ранее использованным тестовым объектам — 17/40 и 11/40. Подробные per-type результаты и методика находятся в `docs/final_i_results.md` и `provenance`.

Мелкие жёлтые номера распознаются слабо. Полная сцена независимо не подтверждена; precision/FPR по всем номерам кадра не заявлены. Повторная проверка карточек в текущий цикл не назначается. Время на GTX1050Ti и работа на другом компьютере не подтверждены. Сохранённый замер на GTX1060: mean54.6ms, p95105.8ms; загрузка окружения/моделей и чтение файлов в этот замер не входят.

Реальные датасеты, обучающие инструменты и тестовые изображения в комплект не включены. Авторство и сведения об источниках: `dataset/ATTRIBUTION.md`. Лицензионные файлы зависимостей сохранены в исходных wheels; инвентарь полного комплекта — `package_inventory.json`. Это техническая сборка проекта; загрузка на площадку сдачи выполняется отдельно.
