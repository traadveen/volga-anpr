# Публикация текущей версии

Решение находится в исходном репозитории https://github.com/traadveen/volga-anpr.git
на ветке main. Точка входа - корневой run.py; команды запуска приведены в README.md.

В коммит входят рабочее решение, модели, датасет, генератор и материалы финальной
адаптации. Checkpoint .pt и массивы .npz обрабатываются Git LFS.
Окружения, кэши, журналы, результаты и старые эксперименты не включаются.

.gitattributes сохраняет байты файлов без преобразования переносов строк:
контрольные суммы остаются действительными после clone и git lfs pull.
Статусы сторонних материалов сохранены в dataset/permissions и licenses.
