# Исправление обычных номеров, 25.10.2026

Рабочий кандидат: FORMAT-CONSISTENCY-20261025.
Точка входа: tools/run_format_consistent.py.
Из CMD для текущих десяти фотографий: show_examples.cmd.
Для своей папки: recognize.cmd --input "D:\photos" --output "output\result.csv" --device cuda --show.

## Что исправлено

1. Ошибочный класс type1b исправляется на type1, если исходный OCR целиком
   соответствует формату обычного номера, каждый символ проходит прежний порог
   уверенности, а проверенная наблюдаемая рамка имеет однострочную форму.
   Символы OCR не заменяются. Исходный класс остаётся в диагностике.
2. Сохранённый детектор F03/BEST-G дополняет текущий детектор рамками обычных
   длинных номеров. Существующие детекции сохраняются; пересекающиеся и вложенные
   повторные рамки не добавляются. Дополнительный результат выдаётся только
   для полного допустимого текста с достаточной уверенностью символов.
3. В CMD добавлен recognize.cmd, а show_examples.cmd переключён на новый кандидат.
   Для запуска из CMD PowerShell больше не требуется.
4. В SOURCES.csv исправлен фактический тип type1_04.jpg на type1a.
   Исходные фотографии и их имена сохранены для воспроизводимости диагностики.

Первичные веса детектора и OCR сохранены. Дополнительный детектор взят из
существующего BEST-G. Обучение не выполнялось. AUDIT-FIX сохранён отдельно,
и его проверка целостности также проходит.
